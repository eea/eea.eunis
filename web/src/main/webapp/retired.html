Dear EUNIS user,

The EUNIS web application is retired. The software behind it can no longer be maintained. The underpinning EUNIS database continues to be updated, and its content is integrated into the Biodiversity Information System for Europe, BISE. The European Environment Agency is still improving the visualisation and layout of the EUNIS content in BISE. In case you don’t find the information you used to access from the EUNIS web application, please contact us at bise@eea.europa.eu.

  • Search habitats in BISE https://biodiversity.europa.eu/resources/search-habitat
  • Search species in BISE https://biodiversity.europa.eu/resources/search-species
  • Search protected and conserved areas in BISE https://biodiversity.europa.eu/resources/search-protected-areas
